# 黑神话悟空 · 收集图鉴管理

一个单文件、离线可用、可云同步的《黑神话：悟空》全收集管理工具。勾选即收藏，自动统计进度，支持属性 / 特性查看、标签、筛选补缺，进度可存本地、烘焙进文件、或同步到 GitHub。

> 版本：**v1.1.0** · 单文件 HTML · 零依赖 · 零构建

---

## 功能

- **9 大类 · 300+ 收集项**：武器 / 披挂（头冠·衣甲·臂甲·腿甲）/ 珍玩 / 葫芦·酒 / 泡酒物 / 种子 / 丹方 / 材料（5 类）/ 精魄。
- **属性与特性**：武器填攻击/暴击/防御/耐性 + 独门妙用；披挂填套装归属 + 神珍防御；珍玩填被动；泡酒物填喝酒效果；种子填产出药材；丹方填炼制丹药。
- **勾选收藏 + 实时进度**：顶部总进度条 + 每个分类 `已收/总数`。
- **标签系统**：预设标签（易漏 / 二周目 / BOSS / 隐藏 / 支线 / 豪华版）+ 自定义标签，专门对付一周目永久错过的那批。
- **筛选补缺**：搜索框（名称/属性/效果/备注/标签）+ 仅未收集 + 易漏优先 + 仅二周目。
- **三种进度持久化**：
  1. 💾 **离线存档**：把进度烘焙进一份新的 HTML 下载，双击即记得，不依赖浏览器、不联网。
  2. ☁ **GitHub 云同步**：进度推到仓库 `state.json`，任意设备打开自动加载（首次需填一次 Token，仅存本机）。
  3. **导入 / 导出**：JSON 备份，可迁移或防丢。

## 用法

### 方式一：本地双击（最简单）
直接用浏览器打开 `wukong-collector.html` 即可。所有数据存在本机浏览器，**无需联网**。

### 方式二：GitHub Pages（随时访问）
已部署在 `https://zhewenzhang.github.io/wukong-collector/wukong-collector.html`。

- 首次打开点「☁ 云同步」→ 粘贴你的 GitHub Personal Access Token（fine-grained，仅授权本仓库 `Contents` 读写）→ 「配置并同步」。
- 之后勾选 / 改备注 / 打标签会**自动保存**到仓库 `state.json`，换设备打开自动加载。Token 仅存你这台浏览器，不进网页源码。

### 方式三：离线存档（最稳，跨设备靠文件传递）
点「💾 离线存档」生成一份带进度的 HTML，双击那份文件即可看到全部勾选。适合不想配 GitHub、或隐私模式 / 预览面板下 localStorage 失效的场景。

## 稳定性设计

- **状态归一化**：`done / notes / tags` 始终为对象，破损的烘焙数据或旧备份不会导致白屏。
- **localStorage 容错**：隐私模式 / 存储不可用时静默降级，不抛错。
- **云同步重试**：网络抖动时自动重试一次；后台保存有轻提示（toast）反馈成败。
- **初始化兜底**：首屏渲染包在 try/catch 中，单条数据异常只跳过该条目，不会整页崩溃。
- **烘焙防截断**：备注中的 `</script>` 会被转义，生成离线文件不会破坏页面。

## 数据来源与免责

属性 / 效果数据基于公开攻略整理（萌娘百科 / B 站 wiki / 游民星空等），为游戏内**参考值**：

- 武器数值取自萌娘百科；披挂防御取神珍品质、套装详细效果与部分独门妙用以游戏内图鉴为准。
- 葫芦 / 酒子类为参考清单，拿到游戏内对照图鉴补全最准。
- 工具内所有条目均可手动增删、改备注，数据不准可自行校准。
